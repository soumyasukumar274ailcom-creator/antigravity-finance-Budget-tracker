# 🌌 Antigravity Finance OS

A high-end, futuristic personal finance and budget tracker built with **Next.js 16**, **Tailwind CSS 4**, and **Glassmorphism Design Principles**.

![Antigravity OS Banner](https://via.placeholder.com/1200x400/0A0E14/E8F0FF?text=ANTIGRAVITY+FINANCE+OS)

## ✨ Features

- **"North Star" Metric**: Heavier typography and neon glows for your Total Net Worth focal point.
- **Category Pulse**: A merged management module for orbs and budgeting with interactive "Ghost Rings."
- **Ghost Mode**: Premium privacy obfuscation using 12px backdrop-blur and desaturation.
- **Pulse Chart**: Synchronized multi-metric tooltips with dynamic Y-axis scaling.
- **Frictionless Entry**: Floating transaction bar with quick-log category chips and success animations.
- **Theme Engine**: Seamlessly toggle between **Antigravity Dark** and **Cloud Light** modes.
- **PWA Ready**: Installable on mobile and desktop as a standalone application.

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4 + CSS Variables
- **Icons**: Lucide React
- **Charts**: Recharts (Customized)
- **State**: Custom React Hooks + LocalStorage Persistence
- **Animation**: CSS Keyframes + Drift-in Utilities

## 🛠️ Local Development

1. **Clone the repo**:
   ```bash
   git clone https://github.com/soumyasukumar274ailcom-creator/antigravity-finance-Budget-tracker.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
